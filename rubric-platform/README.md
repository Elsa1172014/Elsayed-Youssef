# منصة المحكّات المعيارية

منصة ويب مستقلة للمعلمين: يكتب المعلم **الهدف التعليمي** فتولّد المنصة **3 محكّات** للتقييم الذاتي بصيغة المتكلم وبأربعة مستويات (متقدّم جدًّا، متقن، نامٍ، مبتدئ). يُحفظ كل هدف في مكتبة مشتركة، ويُنزَّل ملف **Word** (ورقتا A4، قصاصات متلاصقة بنصف سم لخط القص).

لا يحتاج المعلم إلى حساب Claude: يدخل باسمه ورمز دخول مشترك يضعه رئيس القسم.

## البنية

| الجزء | الملف | الوظيفة |
|---|---|---|
| الواجهة | `public/index.html` | صفحة واحدة بلا خطوة بناء: الدخول، التوليد، تعديل الجدول، المكتبة، تنزيل Word |
| التوليد | `api/generate.js` | يستدعي Claude من الخادم (المفتاح لا يصل المتصفح) ويحفظ الهدف |
| المكتبة | `api/goals.js` | عرض الأهداف وتعديلها وحذفها (لصاحبها فقط) |
| الدخول | `api/login.js` | يتحقق من رمز الدخول المشترك |
| التخزين | Upstash Redis | يُربط من Vercel بنقرتين |

## النشر على Vercel

1. **مفتاح Anthropic:** أنشئ مفتاحًا من console.anthropic.com، وحدّد سقف إنفاق شهريًا من إعدادات الحساب.
2. **استيراد المستودع:** في Vercel اختر Add New → Project، واختر مستودع GitHub، ثم اضبط **Root Directory** على `rubric-platform`. لا تغيّر بقية الإعدادات (يقرأ Vercel الملف `vercel.json`).
3. **قاعدة البيانات:** من تبويب Storage في المشروع أضف **Upstash Redis** (من Marketplace). يضيف Vercel المتغيرين `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN` تلقائيًا.
4. **المتغيرات:** من Settings → Environment Variables أضف:
   - `ANTHROPIC_API_KEY`: مفتاح Anthropic.
   - `ACCESS_CODE`: رمز الدخول الذي ستعطيه للمعلمين.
   - اختياري: `ANTHROPIC_MODEL` لتغيير النموذج (الافتراضي `claude-opus-5-5`).
5. اضغط **Deploy**، ثم وزّع الرابط ورمز الدخول على المعلمين.

بعد تغيير أي متغير أعد النشر (Redeploy) ليأخذ التغيير.

## التشغيل المحلي

```bash
cd rubric-platform
npm install
cp .env.example .env   # ثم املأ القيم، وصدّرها في الطرفية أو استخدم vercel dev
npm run dev            # http://localhost:3000
npm test               # يفحص الواجهات الخلفية بخوادم وهمية، بلا مفاتيح حقيقية
```

## حدود يجب معرفتها

- **الأمان:** رمز الدخول مشترك. من يعرفه يستطيع التوليد. غيّره من Vercel إذا تسرّب. اسم المعلم يُكتب عند الدخول ولا يُتحقَّق منه، فحذف الأهداف وتعديلها محميّان على مستوى الاسم فقط.
- **التكلفة:** كل توليد استدعاء مدفوع لـ Anthropic. اضبط سقف الإنفاق في حسابك.
- **المدة:** التوليد يستغرق عادة بين 10 و40 ثانية، والحد الأقصى للدالة 60 ثانية.
