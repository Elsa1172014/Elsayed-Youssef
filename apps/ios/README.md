# iOS / tvOS (SwiftUI, AVPlayer)

`ReceiverKit` is a Swift package with the API client and models. `ReceiverApp.swift.txt` is a starter app view to copy into a new Xcode iOS/tvOS target.

**Status: source skeleton, not yet compiled or run in CI** (no Swift toolchain in the build environment). Next: sign-in, EPG, search, PiP, tvOS focus handling. Publishing needs the owner's Apple Developer Program membership and signing certificates (docs/DEPLOYMENT.md).
