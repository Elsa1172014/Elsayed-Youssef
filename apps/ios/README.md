# iOS / tvOS (SwiftUI, AVPlayer)

`ReceiverKit` is a Swift package with the API client and models. `ReceiverApp.swift.txt` is a starter app view to copy into a new Xcode iOS/tvOS target.

**Status: source skeleton, not yet compiled or run in CI** (no Swift toolchain in the build environment). **Not on the release path:** the product is the web app (store publishing was cancelled by the owner). Kept as an optional skeleton.
