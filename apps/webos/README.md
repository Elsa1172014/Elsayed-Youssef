# LG webOS TV

Packages the web app (`apps/web`) as a webOS web app. Stage with `apps/package-tv.sh webos https://your-api.example`, then run `ares-package` and install with `ares-install` (developer mode) or submit via LG Seller Lounge with **your** account. Not yet verified on a device or emulator.
