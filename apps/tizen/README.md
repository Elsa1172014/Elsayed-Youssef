# Samsung Tizen TV

Packages the web app (`apps/web`) as a Tizen web app. Stage with `apps/package-tv.sh tizen https://your-api.example`, then sign and package with Tizen Studio / `tizen package` using **your** Samsung author certificate. Not yet verified on a device or emulator.
